# 🌊 Rising Waters: A Machine Learning Approach to Flood Prediction

## Overview

This project predicts flood occurrence using Machine Learning models trained on a public flood dataset. A Flask web application allows users to enter environmental parameters and receive a flood prediction.

## Features

- Data preprocessing
- Exploratory Data Analysis (EDA)
- Decision Tree
- Random Forest
- K-Nearest Neighbors
- XGBoost
- Accuracy comparison
- Confusion matrices
- Classification reports
- Responsive Bootstrap interface
- Flask deployment

## Technologies

- Python 3.10
- Flask
- HTML
- CSS
- JavaScript
- Bootstrap
- Scikit-learn
- XGBoost
- Pandas
- NumPy
